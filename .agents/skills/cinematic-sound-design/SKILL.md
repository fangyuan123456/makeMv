# 电影声音设计与拟音声景技能指南 (Cinematic Sound Design & Foley)

“声音是电影的另一半。”画面确立空间，声音注入生命。本技能规范电影级物理拟音（Foley）、空间声景（Ambience）、对白声学环境、配乐情绪点与声画连续性剪辑语法。

---

## 0. 工序阶段权责与使用时机映射表 (Phase & Ownership Matrix)

声音在影视摄制台本中必须与画面同步规划，并在后期总装中完成声画缝合：

| 管线阶段 | 对应执行工具 | 核心法定权责（本阶段专属） | 绝对红线禁区（严禁越权） |
| :--- | :--- | :--- | :--- |
| **阶段 A：上游分镜台本规划** | `film.shooting_script` | ① **提炼逐镜现场物理拟音**（脚步受力、衣料摩擦、器具接触）；<br>② **空间声景底噪 (Room Tone)** 锚定；<br>③ **100% 刚性保留原剧情全部角色对白与台词**（输出至 dialogue 字段）；<br>④ 拟音结果输出至 `soundEffects` 字段。 | ❌ 严禁压缩、省略或篡改原剧情台词对白；<br>❌ 严禁遗漏关键剧情物体的物理碰撞拟音。 |
| **阶段 B：单镜首帧与视频生成** | `film.shot_frame_prompt`<br>`film.shot_video` | ① 视觉画面为声音提供发声源物理依据（如手持金属器物触地、门扇推开）。 | ❌ 严禁出现“画中有声却无发声源”的穿帮。 |
| **阶段 C：后期剪辑与游戏总装** | `game.assembly` / 后期渲染 | ① **声画连续性组接**（J-Cut 音效先入 / L-Cut 声音延续）；<br>② **空间混响匹配**（密室短混响、荒野无混响）；<br>③ **主观静音震撼**（关键创伤时刻骤然抽空声音）。 | ❌ 严禁两镜切换时声音突兀截断爆音。 |

## 1. 电影声音层级金字塔 (The 4-Layer Sound Architecture)

```
        ▲      [ 1. 对白 (Dialogue & ADR) ] —— 叙事核心、情绪载体、清晰度最高
       / \
      /   \    [ 2. 物理拟音 (Foley & Hard FX) ] —— 骨骼受力脚步、衣料摩擦、器具碰撞
     /     \
    /       \  [ 3. 环境声景 (Ambience / Room Tone) ] —— 穿堂风、远方雷鸣、空间空气感
   /─────────\ [ 4. 配乐动机 (Score / Leitmotif) ] —— 心理潜台词、情绪波峰推进
```

## 2. 物理拟音分级系统 (Foley Categorization) · 【阶段 A 上游台本提炼】

拟音是让观众相信画面物理真实性的第一锚点。镜头中的每一个接触，都必须具备精准的质地：

| 拟音类别 | 涉及物理动作 | 质感与材质声音描述范例 | 戏剧功能 |
| :--- | :--- | :--- | :--- |
| **足音脚步 (Footsteps)** | 迈步、跨门槛、跪坐、急刹 | “硬底鞋踩在潮湿木地板上，发出沉闷受力的嘎吱微陷声”；“脚步或手杖钝底顿在石板地面上的短促清脆磕击声”。 | 交代人物体重、健康状态、心理慌乱或从容。 |
| **服饰布料 (Cloth Move)** | 抬臂、转身、下摆飘动 | “厚重粗布/大衣在穿堂风中掠过的干燥摩擦声”；“皮衣受力紧绷的沉实皮革拉扯声”。 | 增强动作的空气动量与人物沉重感。 |
| **道具物理交互 (Props / Handling)** | 磕地、拔刀、推门、端茶、机械操作 | “生锈铁轴与厚重门框挤压摩擦发出的高频尖锐吱呀声”；“金属器物轻触地砖发出的微弱清脆脆响”。 | 道具质感与关键线索实体化。 |
| **身体冲击与受力 (Body Impacts)** | 跪倒、撞墙、拳肉搏击、拍案 | “身体重重砸在地面/垫面上的沉闷扑响”；“手掌拍在桌面上的沉重震荡音”。 | 痛感传递、力量宣泄。 |

## 3. 空间声景与空气混响 (Ambience & Acoustic Space)

声音必须严格匹配场景的物理声学特征（杜绝干瘪无混响的录音棚干声）：

1. **封闭/半封闭室内（如老宅、地下室、密室）**：
   - **底噪 (Room Tone)**：风声穿过门窗缝隙的低沉哨音、室内微弱电流或火苗噼啪声、木质/金属结构的轻微热胀冷缩声；
   - **混响 (Reverb)**：中短混响，墙面与陈设吸收部分高频，低频略有共鸣。
2. **空旷旷野/荒村废墟**：
   - **底噪**：深邃狂风扫过枯草的萧瑟沙沙声、极远处不知名寒鸦的一声啼鸣；
   - **混响**：几乎无近处反射，声音迅速消散在天地之间，带来空旷无依的孤立感。
3. **主观静音震撼 (Subjective Silence / Auditory Void)**：
   - 在爆炸、至亲暴毙或突发致命真相瞬间，**骤然将一切写实声音抽空**，仅留极细微的高频耳鸣或沉重心跳声；
   - 极具冲击力地表现角色的脑中轰鸣与现实隔绝感。

## 4. 声画剪辑时序法则 (Audio Continuity & Sound Bridges) · 【阶段 C 后期总装】

在影视与影游多镜头组接中，声音是消灭镜头跳跃感的最强粘合剂：

```
画面轴 (Video): [ 镜头 01 · 室内全景 ] | [ 镜头 02 · 门口特写推门 ]
声音轴 (Audio): [ 室内风声与环境底噪 ─── J-Cut ───► 门轴吱呀预先响起 ] | [ 门轴声继续 + 脚步入场 ]
```

* **J-Cut（音先于画）**：下一个镜头的声音在当前镜头画面结束前 0.5~1.0 秒提前切入，诱导观众视线期待；
* **L-Cut（画先于音）**：上一个镜头的声音延续蔓延到下一个镜头的新画面中，维持情绪连贯。

### 4.1 J-Cut 惊悚先行法则 (The J-Cut Suspense Law) · 【阶段 A 台本设计与阶段 C 组接】
在悬疑恐怖、密闭空间或突发危险剧情中，**严禁画面与突发异响在同一帧生硬硬切**（那样会沦为廉价的 Jump Scare，破坏心理厚度）。
必须强制采用 **J-Cut 惊悚先行**：
1. **上一镜尾声（0.5~1.0s）**：画面仍保持受害者的喘息、冷汗面部或幽暗环境，但下一个镜头核心惊悚声源（如指甲刮木声“吱……拉”、门外沉重的铁链拖动声、木门被猛烈撞击声）提前在画外骤然刺入！
2. **下一镜起幅（0.0s）**：顺理成章切至受害者瞳孔骤缩的惊恐反应特写，或直面危险发声源。
3. **心理潜台词**：以纯听觉先行刺穿观众心理防线，让恐惧在黑暗中发酵，画面随后跟进，压迫感呈指数级倍增。
