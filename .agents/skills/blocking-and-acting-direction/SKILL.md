# 导演场面调度与演员表演技能指南 (Blocking & Acting Direction)

好的表演不是蜡像的静止，更不是全景镜头里无意义的“喉结微动”或“呼吸起伏”假动作。本技能定义空间场面调度几何、骨骼级动作力学、身体重心受力与眼神表演规范。

---

## 0. 工序阶段权责与使用时机映射表 (Phase & Ownership Matrix)

演员调度与肢体表演贯穿台本规划、首帧定格与动态演进，各阶段职责绝对清晰：

| 管线阶段 | 对应执行工具 | 核心法定权责（本阶段专属） | 绝对红线禁区（严禁越权） |
| :--- | :--- | :--- | :--- |
| **阶段 A：上游分镜台本规划** | `film.shooting_script` | ① **空间权力三角与宏观站位**；<br>② **走位防瞬移铁律**（跨区域移动必须拆分过渡镜头，交代撑地起身或迈步）；<br>③ **视线匹配与朝向分配**（画左看右、画右看左）；<br>④ **道具物理持有状态跟踪**（收纳入怀、别在腰间，严禁凭空消失）。 | ❌ 严禁在此阶段编写具体的解剖学肌肉着力词；<br>❌ 严禁在此阶段编写秒级微动。 |

## 1. 空间场面调度与权力几何 (Blocking & Power Dynamics) · 【阶段 A 上游台本规划】

场面调度（Blocking）是指演员在三维物理空间中的**站位、朝向与走位动线**。空间关系即权力关系。

```
              【权力顶点：立于台阶/高处/光源中心】
                             ▲
                            / \
                           /   \
                          /     \
    【从属/防守者：退于暗影边缘】 ◄────► 【侵入/挑战者：迈步逼近私人空间】
```

### 1.1 经典站位与权力模式
1. **高度差权力法则 (Vertical Dominance)**：
   - 站立者对跪坐/倒地者形成天然压迫；
   - 站立者若突然弯腰俯身逼近，压迫感呈指数级倍增；若颓然坐下，则代表权力瓦解或内心破防。
2. **空间侵入法则 (Proxemics & Spatial Invasion)**：
   - 社交距离（2米外）→ 警戒对峙；
   - 亲密距离（0.5米以内）：非极度亲密，即极度危险（暗杀、威胁、低语交涉）。
3. **纵深调度 (Deep Space Blocking · 走位变景别)**：
   - 摄影机固定不动，角色从**后景深处（远景状态）**径直大步走向**前景镜头前（大特写状态）**；
   - 画面动能极其强大，空间透视瞬间拉伸，视觉冲击远超单纯的机械变焦。
4. **【⭐ 走位防瞬移铁律】**：
   - 角色在空间中的位移必须有物理连续性。严禁前一镜头角色还在偏僻角落蜷缩，下一镜头直接在中央大案前站立操作！
   - 必须通过**“撑墙站起 ➔ 迈步挪向案前 ➔ 最终站定”**的物理走位切片完成空间过渡。

## 2. 骨骼动作力学三步法则 (Kinetic Mechanics Law) · 【阶段 C 下游视频动态】

任何有说服力的物理动作，必须符合完整的运动力学三部曲：

```
[ 1. 预备蓄势 Anticipation ] ──> [ 2. 爆发执行 Kinetic Release ] ──> [ 3. 惯性缓冲 Follow-through ]
(重心压低/手臂后撤/吸气收缩)     (骨骼位移/跨步/推门/拔刀/拍案)     (衣摆翻飞/余震刹停/重心复位)
```

### 2.1 常见动作错误 vs 正确骨骼级动作（按景别匹配动能）
* ❌ **错误假微动（尤禁用于全景/中远景）**：“角色神情严肃，眼神微动，呼吸起伏”（全景下亚像素动作不可见，模型生成出来如同蜡像微颤）。
* ✓ **正确骨骼动作**：
  * **入门动作**：“右手手掌抵住门扇边缘向前推开，右腿率先跨过门槛，身体重心随之明显前倾，衣摆随步幅向后自然摆动。”
  * **伏案/俯身动作**：“双手撑住桌面边缘，上身自腰部向前倾折，肩胛骨微隆起，视线低垂聚焦于桌面文件。”
  * **惊觉动作**：“双手骤然收紧握住手中物品，指节受力发白，头部猛然向声源侧扭转，上身向反方向微撤呈防御姿态。”

## 3. 身体受力与重心分析 (Center of Gravity & Grounding) · 【阶段 B 中游生图专属】

画面是否具有物理真实感，核心在于**身体受力与重心的交代**：

| 姿态类型 | 重心分布与受力支点 | 视觉解剖学特征 | 心理潜台词 |
| :--- | :--- | :--- | :--- |
| **虚弱/负伤行走** | 重心偏向健侧，主要受力在拐杖、扶手或墙面 | 躯干向单侧倾斜，双肩一高一低，步幅迟缓 | 疲惫隐忍、暗伤缠身、行动受阻。 |
| **警戒对峙站姿** | 重心位于双脚之间，两脚微错开抓地 | 膝关节微屈成蓄力状，下颌微收，双肩微耸防御 | 随时准备闪避或反击。 |
| **跪坐/低位姿态** | 重心落在脚踝、膝部与支撑面接触点 | 臀部或双膝承重，腰背微弓或挺直，肢体紧绷 | 漫长等待、孤立无援、压抑或屈服。 |
| **逼近俯身姿态** | 重心压向前倾的支撑手臂（如按在桌面或扶手） | 肘部锁定承重，颈椎前伸，上身侵入对方上方空间 | 强势压迫、主导掌控、步步紧逼。 |

## 4. 眼神戏与微表情表演 (Eyeline & Micro-Expressions) · 【阶段 B 锁定 + 阶段 C 传导】

眼睛是戏剧之魂。微表情不是乱挤肌肉，而是神经张力的传导：

1. **视线锁定 vs 视线逃逸**：
   - **锁定 (Locking)**：双眼死死扣在对手眉心，眨眼频率极低，代表绝对杀意或心理审判；
   - **闪烁逃逸 (Darting)**：眼球向画左下或画右下迅速瞥移，代表心虚、盘算谎言、搜寻逃跑路线；
   - **低垂绝望 (Cast Down)**：视线凝固在地面特定物件（血迹、相机、信物），下眼睑颤动，对外界刺激麻木。
2. **面部肌肉的真实受力**：
   - 咬肌隆起紧咬（牙齿咬死）；
   - 眉骨深锁下压（眉间形成两道深纵纹）；
   - 瞳孔骤缩（遭遇致命危机或巨大打击瞬间）。
3. **戏剧张力物理外化与纯正向描述**：
   - 严禁使用“各怀心事/神情复杂”等抽象心理词，必须转化为可视物理表现（如身体微倾、指节收紧、视线错开）；
   - 表达独处或特定站位时使用纯正向肯定句，避免“无……/严禁……”等否定词。

## 5. 重力解剖与道具三点物理接触公理 (Gravity Grounding & Prop Contact) · 【阶段 B 中游生图刚性红线】

### 5.1 重力解剖与着力点公理 (Gravity Grounding & Anatomical Folding)
严禁使用抽象形容词描写非站立姿态（如只写“害怕地蜷缩”）。扩散模型受站姿肖像先验严重干扰，必须显式描写【重力接触点与肢体几何折叠】：
* **蹲姿/蜷缩**：必须明确写出“臀部与脚踝贴地，双膝紧紧曲起抵在胸前，身体重心极低，后背死死贴住墙面发抖，身体紧缩成一团”，绝不可使用站立姿态；
* **跪姿/卧姿**：必须写出“双膝跪地、小腿平贴地面”或“侧卧贴地，手肘撑地”；
通过解剖学上的重心下沉与躯干关节折叠，彻底扼杀扩散模型画站姿的本能。

### 5.2 道具三点物理接触公理 (Three-Point Prop Contact)
当角色手持或操作剧情关键道具时，严禁只写模糊的“手里拿着道具”或两手空空！必须建立【手部握持位置 + 道具特定部位 + 与环境/地面的接触关系】的三维物理力学闭环：
* **手持长杆或长道具（手杖/长棍/刀鞘/工具/烟杆）**：“右手死死抓握细长握柄，把端垂直抵在身旁的地面上，指节用力发白紧绷”；
* **手持纸张/符纸/令牌**：“右手食指与中指紧紧捏住符纸上端，符纸下缘垂在胸前”；
三点接触将道具死死钉在角色手中与空间环境中，杜绝道具漂移、变形或两手空空。
