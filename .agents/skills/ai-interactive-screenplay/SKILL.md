# 工业级 AI 互动影视短剧抉择剧本技能指南 (AI Interactive Screenplay)

本技能提供专为 **AI 视频生成管线（生图、视频时序动态直出）** 量身定制的互动影视与短剧抉择剧本创作工业规范，适用于任何故事题材。

> [!IMPORTANT]
> **AI 视频生成核心铁律**：
> 这里的剧本**不是供人类演员自由发挥的感性文学，而是下游 AI 视频生成模型的唯一指令母本与资产生成蓝图**！
> 剧本中的每一行描写，必须严格经过**“AI 视频模型可生成性过滤”**——采用强代入视角直奔高压冲突，确保分支动能物理连续，严控场景资产膨胀，使互动抉择能以极高稳定性转化为高质量视频。

## 0. 工序阶段权责与使用时机映射表 (Phase & Ownership Matrix)

| 管线阶段 | 对应执行工具 | 核心法定权责（本阶段专属） | 绝对红线禁区（严禁越权） |
| :--- | :--- | :--- | :--- |
| **阶段 1-A：故事基石与分幕大纲** | `planner.screenplay_writer`<br>(01-premise) | ① 确立故事题材、核心对立矛盾与世界观基调；<br>② 核心角色小传、内在动机与视觉锚点；<br>③ 分幕结构节拍表与互动抉择点规划。 | ❌ 严禁无大纲直接编写正文；<br>❌ 严禁使用虚假合流（MERGE）；<br>❌ 严禁编写分镜头单或生图提示词。 |
| **阶段 1-B：全景互动剧本文学推演** | `planner.screenplay_writer`<br>(02-screenplay) | ① 分幕剧本文学正文编写；<br>② POV/贴身压迫视角、物理可观测动作流与分支动能承接；<br>③ 潜台词对白交锋与现场音效预埋；<br>④ 互动抉择点与专有终局结算落地。 | ❌ 严禁出现心理独白、非物理抽象词或遮挡物内部不可见细节；<br>❌ 严禁出现摄影机景别与画质术语；<br>❌ 严禁出现任何虚假合流标记。 |
| **阶段 1-C：PRD 分幕因果拓扑** | `planner.script_to_prd` | ① 将文学剧本转换为 DAG 有向无环因果图；<br>② 节点依赖、分支选择与终局收敛。 | ❌ 严禁产生拓扑死循环或悬空孤立分幕；<br>❌ 严禁篡改文学剧本既定剧情与台词。 |

## 1. 视角定位与开局节奏（最高纲领）

### 1.1 紧贴主角单视点高压对峙视角（Close Single-POV）
- **体验与算力痛点**：全知上帝视角容易剧透且削弱临场感，而单段堆砌过多连续肢体交互会导致视频生成穿帮或畸变。
- **剧本规范**：
  1. **紧贴主角单视点（主角可正常出镜）**：统一使用主角法定姓名（与角色定妆资产对齐），所写所听严格限定在主角当下感官范围内，聚焦近距离正面逼问、贴身过肩对峙与微表情反应；
  2. **少动作、重对峙（防混战崩坏）**：**每幕只保留 1~2 个核心物理动作**（如武器抵近、掀开箱盖、推开木门），把篇幅留给 **2~4 轮狠辣短促对白与停顿喘息**，自然收束在“对手盯住主角等待表态”的抉择悬停点。

### 1.2 开局即高压现场法则（In Medias Res，弱铺垫重刺激）
- 第一幕必须**在开头第 1~2 句话内**直接落在危机爆发、贴脸对峙或剑拔弩张的当下瞬间（如武器/道具抵近、当面抓包、异常突发），直接跳过进门、寒暄与前情交代；
- 故事背景与恩怨不在正文里大段解释，仅通过高压对白顺带带出或刻意留白。

### 1.3 宏观骨架与篇幅密度区间
```
【第一幕：起 (Setup & Crisis)】 ➔ 【高压贴脸开局 (0-5s)】 + 【核心困境确立】 + 【入局不可逆事件】
               │
               ▼
【第二幕：承/转 (Confrontation)】 ➔ 【两极交锋】 + 【鸿沟落差 (The Gap)】 + 【重大命运抉择 (Decision)】
               │
               ▼
【第三幕：高潮/合 (Resolution)】 ➔ 【至暗时刻】 + 【代价兑现】 + 【专有命运结算 (Ending)】
```
- **单幕正文篇幅**：控制在 **250~450 汉字**（硬上限不超过 550 字），短小精悍，靠对白与停顿拉张力；
- **全剧总篇幅**：控制在 **800~1400 汉字**，高密度推进，拒绝注水与连续混战动作。

## 2. 互动分支机制：抉择即命运（拓扑、两难与倒计时）

```
                       【序幕 / 危机降临】
                                │
                                ▼
                   【重大命运抉择点 (Decision Point)】
                         /             \
                        /               \
          [ 选项 A: 孤注一掷抗争 ]      [ 选项 B: 妥协交出筹码 ]
                  │                               │
                  ▼                               ▼
        【专有支线: 绝境突围之路】      【专有支线: 隐忍周旋寻机】
                  │                               │
                  ▼                               ▼
        【专有终局 1: 惨烈殉道结局】    【专有终局 2: 独自承担代价】
```

### 2.1 彻底废除合流机制 (No Lazy Merging)
- **公理**：彻底废除“选 A 还是选 B，两句台词后又合并回同一条主线”的伪互动骗局！
- **物理因果律**：每一个选择都是一次不可逆的命运撕裂。一旦做出重大抉择，人物关系、生死存亡、道具归属发生不可动摇的改变，必须走向专有的故事支线或专有终局结算！结局数量随剧情后果自然产生，绝不为了限制结局数量强行合流。

### 2.2 全剧精简分支、“统一互动节点”与分支动能承接
- **分支克制**：全剧设定 **1 到 2 个真正震撼灵魂的命运分支节点（`isBranching: true`）**即可，按需使用不必写满，切忌滥设琐碎无意义的废选项；
- **单线沉浸互动（`isBranching: false`，零分支、零额外视频算力）**：
  - 普通幕末尾可按剧情需要插入单线互动（`SEARCH` 场景找东西/搜证、`HOLD` 长按屏息或蓄力、`QTE_TAP` 连点破局、`TIMING` 靶区格挡/躲避、`CLICK` 关键动作触发），玩家通过末帧交互与前端动效/音效反馈完成动作或获取状态标签（如 `+ledger`），**随后统一推进至同一个下一幕**，在不增加视频算力的前提下保持全程交互感；
- **命运分支互动多样化 & 起幅铁律**：分支点支持 `TIMED_CHOICE`、`CHOICE`、带超时分叉的 `SEARCH`/`HOLD`/`QTE_TAP`/`TIMING` 及按需使用的 `ACTION_ZONE`；每幕正文演到互动触发前的悬念起幅瞬间即止（严禁提前剧透互动结果），幕末统一以 `### 【互动钩子：单线/分支 <KIND> | ...】` 块书写。
- **代价平衡**：不设“最优解”或“正确答案”。每个分支结果必须同时附带**无法挽回的沉重代价**与**一线生机**。
- **分支动能与时空无缝承接**：
  - 抉择点出现时，必须清晰定义此时**人物的物理站位、姿态、手持道具及目光焦点**（基准起幅）；
  - 凡【走向：推进主线】的选项，其物理去向必须与下一幕开篇场景严格一致：原地反制/周旋则下一幕沿用当前母场景，若选项动作转移至另一处母场景（全剧 2~3 个母场景上限内），下一幕开篇必须同步切至该目标母场景；
  - 无论选项走向终局还是推进至下一幕，其后继正文的首句**必须严格承接抉择点的物理初速度与姿态**，并直接交代该抉择动作的即时物理结果，不跳过关键过渡。

### 2.3 道德两难困境与倒计时压迫
| 困境模型 | 核心张力 | 选项设计范式 | 后果分化 |
| :--- | :--- | :--- | :--- |
| **信义 vs 生存** | 恪守底线还是保全眼前活命 | **[选项 A]** 坚守核心承诺/证物不退；<br>**[选项 B]** 放弃立场保全性命撤离。 | 选项 A 走向牺牲或惨胜；选项 B 走向背负代价的流亡/余生线。 |
| **情感 vs 大义** | 拯救至亲挚爱还是阻止全局灾难 | **[选项 A]** 牺牲全局安全换取特定对象生机；<br>**[选项 B]** 承受撕裂亲手切断隐患。 | 极致的人性撕裂，没有绝对胜利者，只有专有的创伤余韵。 |
| **真相 vs 庇护** | 揭穿残忍真相还是维持善意谎言 | **[选项 A]** 当面揭开残酷真相；<br>**[选项 B]** 隐瞒实情维持脆弱和平。 | 选项 A 引发阵营决裂与爆发；选项 B 维持暗流涌动的表面平衡。 |

- **心跳倒计时**：关键抉择界面限制 5 ~ 10 秒决断，屏幕伴随紧张视觉提示与加速心跳拟音；
- **超时默认惩罚**：玩家若犹豫不决超时未选，剧情**不暂停等待**，自动滑向最被动残忍的戏剧后果。

## 3. 高密度对白交锋、现场声景与专有终局

### 3.1 潜台词与 2~4 轮锋利对抗
- **好台词从不直说**：角色绝不通过直球对白自我宣泄情绪或说明书式背诵背景设定；善用试探、隐喻与反问，将真实意图或威胁隐藏在表面字句背后；
- **2~4 轮锋利对抗**：每一场戏的对白严格控制在 **2 到 4 个回合**，砍除日常寒暄，每一句话都施加心理压迫、刺探虚实或改变双方权力平衡。

### 3.2 现场声效线索与专有终局定格结算
- **现场声效线索预埋 (Diegetic Sound Cues)**：在关键戏剧转折点主动嵌入物理拟音（Foley）与空间声景（Ambience）线索（如骤然停止的背景音、器物碰撞清响、沉重脚步声）；
- **专有终局定格结算 (Ending Tableau)**：走向 `ENDING` 的选项，必须以 `【终局：结局名（类型）】` 充分写出该终局的戏剧结算，并给出一个**极具电影视觉象征意味的终局定格画面（80~150 字）**。

## 4. AI 视频物理与视觉防崩准则 (AI Video Native Principles)

1. **物理可观测动作与画框可见性（Show, Don't Tell）**：
   - 100% 翻译为骨骼受力、肌肉微动态、视线焦点或道具物理交互；
   - 物体处于闭合或遮挡状态时，只写外部表面或缝隙可见的物理变化，不描写内部看不见的细节。
2. **动作动能解耦（单段主导动能）**：
   - 动作段落拆解为清晰的**动作单元（Action Beats）**，每个动作单元只描述**一个主导动能方向**（如转身、踏前一步、举手格挡），不堆砌多次位移和转向的复合长动作。
3. **母场景高度收敛与资产复用（2~3 母场景铁律）**：
   - **全剧母场景严格锁定在 2~3 个以内**，**每幕严格聚焦 1 个核心主场景**；
   - 分支与终局差异化靠**当前母场景内的局内调度**（明暗区域转换、站位与道具状态改变）体现。
4. **强视觉外貌符号锚定**：
   - 人设建立时锁定**高对比度、具象化、物理恒定的视觉锚点**（面部/发型特征、标志性服饰材质剪裁、核心随身信物）。
5. **器官物理外观与环境光影分离（Avoid Eye-Glow & Literary Tropes）**：
   - 五官特征写直观物理材质（如“左眼瞳孔呈灰白浑浊，右眼深色正常”）；
   - 先写外部环境光源照亮面部或侧脸，再单独写神态与视线，保持光源与器官描写分离。
6. **剧本因果闭环与道具物理来源**：
   - 遭遇致命危机被困时，明确写出退路受阻的物理动作；非随身常备的临时道具，须写出在现场特定位置发现并拿起的物理过程。
7. **宏观物理交互规避微观渲染盲区**：
   - 将文字或屏幕读数转化为**纯视觉物理状态**（指示灯闪烁、指针偏移、警报声响）及**宏观实体交互**，避免依赖屏幕小字推动剧情。

## 5. 标准 Markdown 排版格式与结构模板 (Formatting Spec & Template)

### 5.1 全系统唯一 Markdown 排版格式 (SSOT)
- **分幕标题**：`## 第 X 幕《幕名》`
- **场景与光影锁**：`【场景：地点，环境细节，光影与氛围】`
- **人物台词与动作**：`[角色名]：“台词内容”`（动作描写紧随或穿插于独立短行，简短有力）
- **关键资产标记（按需）**：`【获得关键道具：...】`、`【获得关键情报：...】`
- **互动抉择点与去向**：
  ```markdown
  【互动抉择点 X】
  - 选项 A：[选择文本描述] ➔ 【走向：推进主线】 或 【终局：结局名（类型）】
  - 选项 B：[选择文本描述] ➔ 【走向：推进主线】 或 【终局：结局名（类型）】
  ```
- **终局结算标记**：若**抉择选项**走向终局，紧随其后以 `【终局：结局名（类型）】` 充分写出戏剧结算与定格画面（80~150 字），该结局线彻底结束；主线推进至最后一幕时可直接自然收尾，无需强制加该标记。

### 5.2 标准排版结构骨架示例（贴身单视点高压对峙）

```markdown
## 第 1 幕《幕名》

【场景：核心母场景名称，具体环境陈设，时段与光影氛围】

（开局直接切入高压现场：交代主角物理站位、手持关键道具与对手逼近施压的即时危机）

[对手角色]：“（潜台词交锋第 1 轮，近距离逼问或施加压迫）”
（主角简洁物理反应，如手指收紧或侧身防备）
[主角姓名]：“（潜台词反击，揭示核心利益冲突）”

（对手单手举起关键道具对准主角，停在等待表态的临界点）

【互动抉择点 1】
- 选项 A：[行为描述] ➔ 【终局：专有结局名（BE/HE/TE）】
- 选项 B：[行为描述] ➔ 【走向：推进主线】

【终局：专有结局名（BE/HE/TE）】
（紧承选项 A 的物理起幅惯性展开瞬间动作后果，最终定格于极具象征意义的终局画面，80~150 字）
```
