## 🎮 双轨交互体系（Double-Track Interaction）

```text
┌─────────────────────────────────────────────────────────────┐
│                      互动短剧全交互矩阵                       │
├──────────────────────────────┬──────────────────────────────┤
│  Track 1: 沉浸式轻交互 (微互动) │  Track 2: 宏观戏剧分水岭 (分支)│
│  (不影响剧情，零额外视频成本) │  (决定命运走向，裂变多终局)    │
├──────────────────────────────┼──────────────────────────────┤
│ 1. 场景点触搜证 (3处发光点)   │ 1. 信任同盟线 vs 孤狼黑市线  │
│ 2. 拟真脑机通话/回复微信     │ 2. 智斗植入木马 vs 屈服洗脑死局│
│ 3. 态度微轮盘 (冷笑/沉默/反问)│ 3. 解放劳工 vs 升维新神 vs   │
│ 4. 甩证物对质戳穿谎言         │    莫比乌斯轮回 (Time Loop)  │
└──────────────────────────────┴──────────────────────────────┘
```

## 💡 为什么这种设计是当下行业最优解？

1. **解决“手闲着”的问题**：
   - 过去每隔 2 分钟才出一个生硬的选择题，玩家像在“看电视插播问答”；
   - 现在玩家一进入第 1 幕，就能亲自动手去摸搜死者口袋、看终端屏幕，像在玩正经的赛博侦探大作。
2. **解决“成本失控”的问题**：
   - 搜证、发短信、态度轮盘全是**前端 UI 组件交互**，不需要为每个小动作多拍一条 10 秒钟的复杂视频；
   - 保证整部短剧在 10 个视频切片内收束，渲染极快、成本完全可控！
