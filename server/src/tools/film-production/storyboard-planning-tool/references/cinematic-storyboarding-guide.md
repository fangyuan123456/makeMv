# 工业级电影视听语言与分镜规划通用指南 (Cinematic Storyboarding Guide)

> **定位说明**：本指南汇聚专业电影导演学、视听语言教材（如 Steven D. Katz《电影镜头设计》、Daniel Arijon《电影语言的语法》、Robert McKee《故事》等）的核心影视工业方法论，作为系统分镜生成微内核与大模型视听导演的底层知识库。
> **核心铁律**：全题材通用中立、拒绝机械套路枚举、以戏剧节拍为唯一切分骨架、彻底不设镜头上限。

---

## 一、 核心视听哲学：从文学剧本到视听蒙太奇

文学剧本是用文字讲述人物遭遇，而电影分镜是将文字连续流转化为**视听蒙太奇与时空因果网络**。
镜头（Shot）是视听语言的基本单位。镜头切分的本质，是**戏剧注意力的转移（Transfer of Dramatic Attention）**与**戏剧张力的物理承载**。

---

## 二、 镜头切分的底层骨架：戏剧节拍（Dramatic Beat）

在专业剧本拆解中，**“节拍转换点 = 镜头切分点”**。一个场景绝不是一两个镜头走马灯式带过，而是由连续的戏剧节拍紧密扣合而成：

1. **意图改变节拍（Intention Shift）**：角色产生了新的行动目的、动向改变或决策确立；
2. **信息与认知节拍（Information & Discovery）**：新线索揭示、秘密浮现、环境异动或注意力被特定事物吸引；
3. **冲突与力量对调节拍（Conflict & Power Dynamic Shift）**：言语对峙、物理动作爆发、主客地位反转、危机降临；
4. **反应与共鸣节拍（Emotional Reaction & Resonance）**：外部事件引起的主体生理/心理微反应（眼神、呼吸、动作停滞、情绪翻涌）；
5. **视线与注意力焦点转移节拍（Eyeline & Focus Shift）**：视线从环境转移到人物，从全局转移到互动关键焦点，或角色之间视线交锋。

**数量法则（Text-Density Driven）**：
- 每一幕剧本中包含多少个不可再分的戏剧动作节拍，就自然切分为多少个专业镜头；
- 复杂情节幕自然展开为 8~15 镜甚至更多，短过渡幕自然为 4~6 镜；**严禁人为限定镜头数量上限**。

## 三、 摄影机视听语法：景别、机位与动势

### 1. 景别选择律：信息广度 vs 情感亲密度（Information Breadth vs. Emotional Intimacy）
- **远景 / 大全景（Extreme Long / Wide Shot）**：交代宏观时空、空间地理、天地关系、孤独压迫或群体调度；
- **全景（Full Shot）**：展示角色全身肢体动作、空间站位与物理位移；
- **中景 / 中近景（Medium / Medium Close-Up）**：核心叙事工作马（Workhorse Shot），兼顾人物上半身肢体语言与面部表情，展现人际交往与动作交互；
- **近景 / 特写（Close-Up / Extreme Close-Up）**：高情感亲密度与高信息密度，放大瞳孔震颤、微妙嘴角抽动、肢体细微触碰或关键物体特征；
- **大特写 / 微距（ECU / Macro）**：聚焦极具张力的局部细节，制造屏息凝神或极端压迫感。

### 2. 视点与空间轴线律（Perspective & Continuity）
- **客观视点（Objective Camera）**：中立观察者视角，真实呈现场景全貌与动态；
- **主观视点（POV Shot）**：第一人称视线所及，必须紧密结合角色的视线方向与后续反应镜头（Reaction Shot）；
- **关系视点（Over-the-Shoulder / Profile Two-Shot）**：呈现主体间的对话交锋与权力制衡，严格遵循 **180度轴线原则（The 180-Degree Rule）**，保持视线与朝向连贯，杜绝跳轴混乱；
- **三十度原则（The 30-Degree Rule）**：连续组接同一主体的两个镜头时，机位角度或景别跨度必须足够显著，避免画面微跳。

### 3. 摄影机动势律（Camera Dynamics & Pacing）
- **静态镜头（Static）**：凝练、观察、稳定、悬念积聚；
- **推镜头（Push In / Dolly In）**：视听强化、心理聚焦、紧迫感上升、顿悟时刻；
- **拉镜头（Pull Out / Dolly Out）**：视听抽离、孤独感、宏观揭示、余韵悠长；
- **移镜头 / 跟镜头（Tracking / Trucking / Steadicam）**：紧随主体运动，制造极强的临场沉浸感与流动空间感；
- **升降 / 摇镜头（Crane / Tilt / Pan）**：巡视空间、建立视听连接或引导视线焦点转移。

## 四、 工业级分镜“三明治”提示词架构 (Sandwich Prompt Structure)

每一个镜头均应具备自洽、高精度的视听双轨制作信息：

1. **首帧画面提示词 (`firstFramePrompt`)**：
   `[精确景别与机位角度] + [出场角色绑定(精准长相/年龄/服饰/生理状态)] + [空间环境绑定(材质/光影调性/空间纵深)] + [核心视觉构图与画风基调]`
2. **动态表演与运镜提示词 (`videoPrompt`)**：
   `[主体角色的起止微动作与视线落点] + [摄影机精确运动轨迹(推/拉/摇/移/跟)] + [物理互动反馈与动态质感]`
3. **声音与台词规划 (`audioPrompt` / `dialogue`)**：
   `[环境底层音色 Ambience] + [高精动作拟音 Foley/SFX] + [台词语气与潜台词] + [情绪配乐走向 Score]`
