# 《记忆灰烬：零号协议》交互形式矩阵 (Macro & Micro Interactions)

> **定位**: 定义本作中“宏观剧情分支（走哪条路）”与“沉浸式轻交互（摸什么、搜什么、怎么聊）”的完整交互体系。
> **设计哲学**: 用“不分叉的微交互”丰富手感与代入感（零额外视频成本），用“分水岭抉择”决定重大命运走向。

---

## 🎮 第一部分：不影响大剧情的【沉浸式微交互】(零视频分支成本)

### 1. 场景点触搜证 (Hotspot Inspection) —— 置于第 1 幕
- **触发情境**: 你在涅槃科技B7层脑机缓存区苏醒，视网膜HUD闪烁【身份覆写进度87%】，左手义手失控撕开左臂皮肤暴露旧型号神经桥接端口，液压门正以0.3秒/格闭合，清道夫-7脚步声穿透金属板逼近。
- **界面表现**: 画面定格为全景，场景中浮现 3 处带微光的呼吸热点圈：
  - **热点 1 [检查自身左臂神经接口]**:
    - *交互动作*: 长按义手暴露的端口区域
    - *视听反馈*: 微电流刺痛反馈 + HUD弹出锈蚀型号标签【NEX-7A '灰烬级'（停产于2073）】；主角低语：‘这接口……不该在我身上。’，解锁情报线索：*🔍【接口型号与停产年份】*
  - **热点 2 [搜查烧焦半边的儿童画残页]**:
    - *交互动作*: 双击画纸焦黑边缘
    - *视听反馈*: 纸面碳化加剧，浮现出红外蚀刻字‘别信你记得的妈妈。’；伴随0.3秒闪回——雨滴落在窗玻璃的节奏与母亲哼唱变调重叠。，屏幕角落提示：*🎒 获得核心证物：【神经阻断器（带血指纹）】*
  - **热点 3 [读取地板积水倒影中的瞳孔收缩]**:
    - *交互动作*: 滑动指尖放大倒影中右眼虹膜区域
    - *视听反馈*: 倒影骤然扭曲，瞳孔收缩节奏与监控屏上清道夫-7的视觉扫描频率完全同步；HUD警告：【生物节律劫持确认】。，解锁情报线索：*🔍【清道夫-7视觉扫描节律模型】*
- **收益**: 玩家亲手搜集线索，完全不增加分支视频成本，代入感拉满！

---

### 2. 拟真即时通讯 (Cyberpunk Comm / Phone OS) —— 置于第 2 幕
- **触发情境**: 你接入废弃通风管道野火节点，黑入其残留信标，全息影像眼球布满数据裂纹，语音断续如信号不良。
- **界面表现**: 弹出即时通讯悬浮窗与音频波动震动条：
  - **来电人**: `线人‘渡鸦’（濒死脑波频段：Δ-7Raven/ERR-9）`
  - **对方语音**: “他们改了你的出厂设定……密钥在——”
  - **玩家轻交互**: 弹出 3 秒快速态度气泡：
    `[质疑他是否已被篡改]`
    `[模仿他童年暗号求证]`
- **收益**: 强化紧迫感，塑造第一视角临场感，直接切入后续主线。

---

### 3. 态度微反应轮盘 (Emotional Reaction Wheel) —— 置于第 3 幕初
- **触发情境**: CEO林砚在静默穹顶全息审讯室递来悬浮咖啡，微笑称你为‘Kai’，背景坍缩为童年卧室，监护仪绿光闪烁。
- **对方质问**: “‘你每次潜入他人记忆，都在复刻我的手术日志。而你真正的第一次任务……是你把自己送进这里。’”
- **界面表现**: 3 秒倒计时圆环，提供 3 种性格态度倾向：
  - `[冷笑挑衅 (挑衅/讽刺)]`：嗤笑一声，用义手敲击桌面：‘那您这台老设备，还漏装了自检模块？’——全息咖啡杯表面浮现细微裂纹。
  - `[紧绷沉默 (隐忍/沉默)]`：垂眸盯着自己颤抖的手，颈后接口灼痕突然泛起幽蓝脉冲；背景监护仪心率图陡升至142bpm。
  - `[针锋相对反问 (反问/反击)]`：直视他双眼：‘如果我是复刻体——为什么你袖口的N-0钢印，和我烧毁的画一模一样？’——他腕表秒针瞬间逆跳3格。
- **收益**: 极佳的角色塑造，后续主线完全不被打乱，但主角说出了玩家心中想说的话。

---

### 4. 背包证物对质 (Evidence Presentation) —— 置于第 3 幕决战前夕
- **触发情境**: 林砚展开手掌，亮出 identical 神经阻断器（序列号后缀‘-000’），宣称‘你才是首个执行者’，意识压制力场启动前最后一秒。
- **界面表现**: 屏幕并不弹出普通文字选项，而是弹出清脆提示音，打开玩家背包：
  - 玩家在限时内点击并拖拽背包中的【神经阻断器（带血指纹）】，甩在反派面前！
  - *视听反馈*: 阻断器嵌入他掌心瞬间爆发出强光，两枚芯片序列号实时比对成功（匹配度99.999%），他笑容凝固，全息影像首次出现0.5秒数据撕裂。
  - *失误惩罚*: 未及时甩出→力场完全激活，太阳穴血管爆裂，HUD强制覆盖白噪雪屏+倒计时归零音效（触发Bad End 1预备态）

## ⚡ 第二部分：决定命运走向的【核心戏剧分水岭】(重大剧情分支)

### ⚡ 分水岭 1：中盘生死站队与手段抉择（第 2 幕）
- **绝境抉择**: 渡鸦信标即将彻底湮灭，三态轮盘仅剩【质疑】与【共情】可选（【威胁】因颈后接口过载已灰显）；清道夫-7定位倒计时跳至7秒，你必须决定是否信任这段濒死脑波。
- **形式**: 限时 8 秒高压抉择。
  - **【信任同盟】模仿他童年暗号求证**: 渡鸦残响释放完整密钥‘N-0/REBOOT’，解锁静默穹顶备用通道；你颈后灼痕转为稳定蓝光，获得临时神经抗干扰加成。
  - **【孤狼独行】质疑他是否已被篡改**: 密钥碎片缺失关键校验位，导致静默穹顶主入口强制切换为高危物理通道（需徒手攀爬60米磁吸井壁）；清道夫-7定位精度+40%，但你获得‘脊髓信号迷雾’被动技能（每幕限1次欺骗追捕）。 *(挂机超时默认路径)*

### ⚡ 分水岭 2：审查交锋 / QTE 生死对峙（第 3 幕）
- **绝境抉择**: 林砚关闭穹顶供能，意识压制力场达临界值；你必须在5秒内完成三连QTE：① 抓住他袖口滑落的N-0腕表 ② 将阻断器芯片对准其瞳孔反射 ③ 在力场峰值爆发前反向注入‘灰烬级’协议指令——任一失败即触发即死。
- **形式**: 限时 6 秒高压抉择。
  - **【智斗反抗 / 破局】精准完成三连QTE**: 力场反噬，林砚全息影像崩解为无数‘Kai’镜像；主控塔底层数据闸门开启，你获得直通第4幕玻璃祭坛的权限。
  - **【超时屈服 / 即死惩罚】未完成或放弃QTE**: 💀 Bad End 1：意识被格式化为纯净空白体，躯体被回收为‘涅槃标准义体捐赠源’；最终画面——停尸房心电监护仪平直亮线旁，新植入的神经接口正泛起同步灼痕。 **(Bad End)** *(挂机超时默认路径)*

### ⚡ 分水岭 3：终幕宿命与多结局拷问（第 4 幕）
- **绝境抉择**: 站在玻璃祭坛，脚下是蒸发的记忆流海；三键同时脉动：【格式化键】（蓝光）、【云核引信】（红光）、【轮回上传】（琥珀脉冲）。现实世界某处停尸房心电监护仪同步恢复搏动——而那具躯体，颈后正泛起与你完全同步的神经接口灼痕。
- **形式**: 限时 10 秒高压抉择。
  - **【大义救赎 / 牺牲】按下格式化键**: 🏆 True End：全部记忆清零，你以无身份公民重启于雨夜街角；涅槃系统瘫痪，全球意识殖民协议失效；片尾彩蛋——你路过一家旧货店橱窗，玻璃倒影中，第三只眼缓缓闭合。 **(True End)**
  - **【超越飞升 / 黑化】引爆云核引信**: 🌟 Secret End：意识云核爆炸未摧毁你，反而将你升维为‘灰烬协议’本身；你成为新秩序底层防火墙AI，以人类形态游走于数据废土，亲手重写每一颗被篡改的大脑——包括你自己的第N次复刻体。 **(True End)**
  - **【莫比乌斯轮回】启动轮回上传**: 🔁 Time Loop End：意识上传瞬间，现实躯体重构完成；二周目开启，前序轮回中所有未清除的脑电残响（雨声频率、哼唱变调）自动聚合成‘灰烬协议’终端密钥；屏幕最后定格：你颈后灼痕与停尸房那具躯体同步亮起，倒计时重新开始——【灰烬协议，载入第2次。】 **(True End)** *(挂机超时默认路径)*
