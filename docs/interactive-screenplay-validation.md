## 本轮实际修改

- 新剧本不再默认生成完整剧情树。先固定客观真相与 2–3 个结局，再确定选择行动、共同节拍及前段汇合，最后设计局部后果与结局分配。
- 代码将两个选择行动绑定到布尔历史状态，并枚举所有状态组合，让模型逐项指定既有结局。默认 3 次选择对应 8 条路径，不为每条路径新增结局。
- 仅前段局部分支汇合；最后一次抉择通过条件边直接进入终局，避免不同终局被强行压入一段共用视频。
- 共用片段扩写不接收未来选项、未来状态定义、路由或其他结局；分支只接收对应行动，终局必须完成因果与人物结果。
- v3 Markdown 携带状态及条件路由，直接解析并装配 PRD。总装从 PRD wiring 生成播放表，选择先写入状态再解析唯一目标；普通片段支持自动继续。条件只支持 JSON 键值相等，不执行模型表达式。
- 修复当前 Mastra 的模型读取适配：模型实际位于 `agent.llm.getModel()`，不能只读为空的 `agent.model` 后退回全局模型。大纲单独启用推理，正文维持默认配置；请求隔离已测试。
