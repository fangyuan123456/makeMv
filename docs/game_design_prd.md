# 《深海逆光：临界博弈》互动短剧游戏策划案 (PRD)

---

## 一、 项目基本盘与一句话卖点

* **游戏名称**：《深海逆光：临界博弈》
* **游戏类型**：赛博朋克 / 谍战博弈 / 竖屏互动短剧文游
* **玩家身份**：代号“夜雀”的双面特工（表面上是安保基地的清道夫）
* **一句话卖点**：3分钟高压生死逃脱！每一次抉择都是心跳博弈，要么隐入破晓，要么反客为主！
* **核心游戏节奏**：
  **每场戏抛出绝境 ➔ 屏幕弹出互动选项 ➔ 玩家直觉抉择 ➔ 属性即时反馈 ➔ 跳入下一幕或结局**。

---

## 二、 界面长什么样？（玩家看到的 UI 骨架）

采用类似**抖音/快手短剧的沉浸式单手竖屏界面**，界面自上而下分为 4 层：

1. **顶部状态 HUD（危机监视器）**
   * **维克托怀疑度**：一条红黑相间的危险进度条（初始 35%，涨至 80% 触发暴毙）。
   * **随身背包按钮**：常驻右上角，点击可滑出查看持有的随身道具（如假工作证、毒药等）。
2. **上方主视窗（电影级视听画幅，占屏幕 65%）**
   * 高品质短剧画面，带呼吸感微晃与机位推进（如军官贴脸逼视、暴雨走廊冷光）。
3. **中部字幕区（电影台词与内心独白）**
   * 不堆大长篇文字，每屏仅 1~2 句简练有力的对白。
   * 说话人带醒目名牌（如【维克托】），火药味十足。
4. **底部交互区（操作按键）**
   * 平时隐藏，演到关键抉择点时“啪”地直接弹出对应按键让玩家点击。

---

## 三、 玩家怎么玩？（三种核心互动方式）

坚决不做多余冗余操作，全片仅用三种最抓人的互动：

1. **【倒计时生死抉择 (QTE)】**
   * **操作方式**：屏幕中央浮现红色 5 秒倒计时光圈，伴随急促心跳倒数。
   * **爽点体验**：逼玩家凭直觉秒选，一旦犹豫倒数归零，直接判定心虚处决。
2. **【常规分支二选一】**
   * **操作方式**：底部弹出两个大卡片按钮（一个求稳示弱，一个激进冒险）。
   * **爽点体验**：自主掌控主角性格走向与故事命运。
3. **【亮底牌·背包证物出示】**
   * **操作方式**：绝境时唤起半屏背包轮盘，玩家必须挑出能克制对方的致命证据。
   * **爽点体验**：抓准把柄、瞬间反杀对手的智商爽感。

## 四、 全剧戏份编排与玩家通关动线

### 1. 玩家通关动线总览表

| 场次 | 玩家面临的戏剧危机 | 玩家触发的互动操作 | 剧情流转结果 |
| :--- | :--- | :--- | :--- |
| **第一幕：走廊搜身** | 维克托按住公文包（5秒限时生死局） | **选项 A**：主动示弱，交出钥匙引开视线<br/>**选项 B**：当面冷讽，以特权激怒维克托<br/>**超时不点**：心虚僵立原地，冷汗滑落 | ➔ 导向 **第二幕 A（掉包盲区）**<br/>➔ 导向 **第二幕 B（掐喉审讯）**<br/>➔ 判定心虚，直接触发 **【死亡结局 BE】** |
| **第二幕 A：掉包盲区** | 趁对方背身点烟的3秒盲区偷换名单 | **选项 A**：果断盲操，换入空白纸张<br/>**选项 B**：迟疑收手，不敢行险 | ➔ 成功脱身，达成 **【好结局 HE：幽灵破晓】**<br/>➔ 错过时机被抓现行 ➔ **【死亡结局 BE】** |
| **第二幕 B：掐喉审讯** | 被铁手掐喉撞墙，血氧骤降濒死 | **背包出示**：亮出致命把柄【走私私账卡】<br/>**背包出示**：掏错道具或未持把柄 | ➔ 致命反制主管，达成 **【反转结局 TE：反客为主】**<br/>➔ 惨遭捏碎颈骨 ➔ **【死亡结局 BE】** |

### 2. 三大主干心流路线

* **路线一（稳健潜伏流）**：
  走廊示弱引开 ➔ 趁点烟盲操掉包 ➔ 拿公章从容撤离 ➔ **【好结局 HE：幽灵破晓】**
* **路线二（硬核反杀流）**：
  走廊言语硬刚 ➔ 被掐喉悬空濒死 ➔ 掏出黑账反客为主 ➔ **【神反转结局 TE：反客为主】**
* **路线三（惨死淘汰流）**：
  第一幕超时心虚 / 第二幕A手抖迟疑 / 第二幕B没底牌硬撑 ➔ **【死亡结局 BE：当场处决】**

### 3. 各幕核心冲突与互动详解

#### 第一幕：走廊突击搜身（开局高能）
* **情境**：凌晨三点走廊暴雨，肃清主管维克托一把按住了主角藏有潜伏名单的公文包。
* **危机**：维克托冷笑盘问，怀疑度拉满。
* **互动（限时 5 秒倒计时）**：
  * **选项 A（示弱引开）**：“我只是按规矩查配额，这是钥匙，主管请便。” ➔ 怀疑度降低 10%，引他去开锁，进入【第二幕 A】。
  * **选项 B（当面硬刚）**：“查内鬼查到清道夫头上，主管你晋升压力挺大啊。” ➔ 怀疑度暴涨 30%，维克托暴怒，进入【第二幕 B】。
  * **超时未选**：心虚冒汗，维克托直接认定有鬼，拔枪击毙 ➔ 达成【死亡结局 BE】。

#### 第二幕 A：公文包掉包盲区（心理周旋线）
* **情境**：维克托接过钥匙走向排风口点烟，背对主角，留出 3 秒视野盲区。
* **危机**：夹层名单触手可及，换还是不换？
* **互动（二选一）**：
  * **选项 A（果断掉包）**：趁他吐烟瞬间盲换入空白单据 ➔ 维克托查验无误放行，达成【好结局 HE：幽灵破晓】！
  * **选项 B（迟疑收手）**：害怕反光被发现，犹豫中被维克托转头抓了现行 ➔ 怀疑度拉爆，达成【死亡结局 BE】。

#### 第二幕 B：掐喉暴力审讯（搏命反杀线）
* **情境**：维克托暴怒，机械义肢单手把主角死死掐在合金墙上，脚离地，氧气极速下降。
* **危机**：物理力量完全被碾压，硬拼必死，必须亮出致死底牌。
* **互动（亮底牌·背包出示）**：
  * **出示【走私私账卡】**：把卡顶在他胸前芯片上，维克托把柄被抓大惊失色松开手，反被主角拿捏 ➔ 达成【神反转结局 TE：反客为主】！
  * **出示其他或未出示**：维克托机械臂全力收紧，直接捏碎主角颈骨 ➔ 达成【死亡结局 BE】。

## 五、 操作手感与即时反馈（极简游戏感）

为了保证短剧的操作手感像个“真正的游戏”，加入 3 条最轻量但见效极快的规则：

1. **心跳与震感**：
   * 触发 5 秒 QTE 时，手机伴随急促的心跳音效，产生由慢到快的轻微节律震动。
2. **数值飘字与红闪**：
   * 选了安全选项：顶部浮现一行绿色小字 `[-10% 怀疑度]`，进度条回退；
   * 选了危险选项：屏幕边缘闪烁一瞬血红暗光，顶部跳出红色小字 `[+30% 怀疑度]`。
3. **按钮清脆声**：
   * 点击选项带有清脆利落的机械下压音效，拒绝软绵绵无反馈。

## 六、 死亡回溯与多结局重玩规则

1. **【死亡回溯：时光倒流】**
   * 玩家一旦暴毙打出 BE 结局，决不让玩家从头重看！
   * 结算画面中央提供一个醒目大按钮：**【⏪ 时光倒流】**。
   * 点击直接秒速回退到触发该死局的上一个选项界面，允许玩家换个思路重新选择。
2. **【结局图鉴与重玩驱动】**
   * 全剧包含 3 个结局：
     * `HE 幽灵破晓`（胜利逃脱）
     * `BE 当场处决`（失败暴毙）
     * `TE 反客为主`（神级反转）
   * 每次通关后，结算页顶部常驻显示进度：**“结局收集度：1/3，点击开启新轮回解锁隐藏结局”**，激发全结局收集欲望。
